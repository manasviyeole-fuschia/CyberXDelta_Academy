# CyberXDelta Academy - AI-Proctored IAM Assessment Platform 🛡️

A comprehensive, industry-grade online diagnostic assessment and AI proctoring platform designed for Identity and Access Management (IAM) professionals and enterprise cohorts.

---

## 🌟 Key Features

- **⏱️ 30-Minute AI-Proctored Timed Exam Engine**:
  - Auto-submission on timer expiry (00:00) with visual countdown HUD and continuous auto-save.
  - Multi-condition proctoring telemetry: Face/gaze detection, tab/window switch detection, full-screen lockdown, audio anomalies, and dual-monitor/tamper detection.
  - Transparent Proctored Security HUD (Active Recording, Live Risk Meter 0–100, Integrity Check).

- **📋 8-Step Pre-Flight Verification Wizard**:
  - Full candidate identification, camera/microphone stream validation, screen share permission, browser readiness checks, and proctoring honor code agreement.

- **📊 Comprehensive Diagnostic & Audit Dashboard**:
  - Domain proficiency breakdown (Access Management / SSO, Identity Governance / IGA, Privileged Access Management / PAM, Directory Services & Cloud IAM).
  - Proctoring Integrity Audit Report with exact timestamped event logs, risk gauge, and evidence snapshots.
  - Interactive WhatsApp Communication Box for career roadmaps and customized certification strategy.
  - Restricted Live Cohort Access pop-up with direct WhatsApp redirect (`+91 8972065508`) for course syllabus and cohort requirements.

- **🛠️ Admin / Proctor Command Center**:
  - Real-time audit logs, risk score calculations, candidate telemetry review, and proctoring verification logs.

## 💻 Getting Started

### 1. Clone & Install Dependencies
```bash
# Clone the repository
git clone https://github.com/manasviyeole-fuschia/CyberXDelta_Academy.git
cd CyberXDelta_Academy

# Install root dependencies
npm install

# Install frontend and backend dependencies
cd frontend && npm install
cd ../backend && npm install
cd ..
```

### 2. Run the Fullstack Application
```bash
# Start both Backend (Port 8000) and Frontend (Port 5173) concurrently
npm run dev
```

- **Frontend UI**: [http://localhost:5173](http://localhost:5173)
- **Backend API**: [http://localhost:8000](http://localhost:8000)
